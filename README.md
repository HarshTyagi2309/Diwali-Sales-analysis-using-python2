# 🪔 Diwali Sales Analysis using Python

## 🚀 Overview

This project focuses on analyzing **Diwali sales data** using Python libraries such as Pandas, NumPy, Matplotlib, and Seaborn.

The aim is to extract meaningful insights about customer purchasing behavior, product performance, and sales trends during the festive season.

---

## 🎯 Objective

The objective of this project is to:

* Analyze customer purchase behavior during Diwali
* Identify top-performing products and categories
* Understand sales trends and patterns
* Generate insights for business decision-making

---

## 🧠 Features

* Data cleaning and preprocessing
* Handling missing values
* Exploratory Data Analysis (EDA)
* Data visualization using charts and graphs
* Insight generation from sales data

---

## 🛠️ Tech Stack

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn

---

## 📊 Key Analysis Performed

* Gender-wise sales analysis
* Age group analysis
* State-wise sales distribution
* Product category performance
* Top-selling products identification

---

## 📈 Visualizations

* Bar charts
* Count plots
* Pie charts
* Heatmaps

---

## ⚙️ Workflow

1. Load dataset
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Data visualization
5. Insight extraction
